# Backend Config Extraction Playbook

适用场景：
- 一张图同时包含筛选区、列表区、操作区、添加弹窗、排序弹窗、说明表、便签补充
- 后台页面通过红字标注直接给出字段属性

## 抽取顺序

1. 先识别页面与板块
2. 再抽列表列头与操作入口
3. 再抽添加/编辑弹窗字段矩阵
4. 再抽排序弹窗
5. 再抽说明表
6. 最后抽便签补充规则

## 必抽信息

### 列表区
- 列头字段
- 操作列动作
- 图片点击查看大图
- 元数据列：创建人、创建时间、修改时间

### 添加/编辑弹窗
- 字段名
- 控件类型
- 必填/非必填
- 默认值
- 是否可编辑
- 数据来源
- content 固定取值
- 条件展示/条件不可编辑

### 排序弹窗
- 排序对象
- 排序前过滤条件
- 初始顺序
- 删除/关闭后的顺位变化
- 新增后的默认位置

### 说明表
- 每一行枚举项
- 每一行对应效果
- 附加字段
- 异常提示语

### 便签补充
- 反向依赖
- 删除限制
- 精确错误提示
- 适用功能范围

## 高风险漏提项

- 列表区字段只提了“配置列表”，没提具体列头
- 操作区只提了“可编辑”，没提编辑/复用/删除/排序
- 只提了字段名，没提默认值、可编辑性、固定 content
- 只提了“删除失败”，没提“被引用无法删除”和提示文案
- 只提了说明表存在，没逐行提取

## 最低验收标准

一张后台配置组合图，至少应满足：

- 有 `list_area`
- 有 `action_area`
- 有 `edit_modal`
- 若出现排序入口，则有 `sort_modal`
- 若出现说明表，则有 `field_rule_table`
- `edit_modal` 中每个关键字段都有 `control_type / required / editable`
- 删除限制若出现，必须进入 `field_rules` 或 `section_rules`

## 结构化映射建议

- 列头 -> `visual_elements` + `field_candidates`
- 操作按钮 -> `interactive_entries`
- 红字注释 -> `field_candidates` + `field_rules`
- 说明表 -> `field_rule_tables`
- 若说明表解释的是字段效果，补充“所属字段”语义，不把它当独立配置对象
- 便签规则 -> `section_rules` + `field_rules`
