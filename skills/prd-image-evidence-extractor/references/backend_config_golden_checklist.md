# Backend Config Golden Checklist

适用场景：一张图同时包含搜索区、列表区、操作区、添加/编辑弹窗、排序弹窗、说明表、系统说明或黄色便签。

本清单用于把已验证有效的后台配置页抽取标准固化为黄金样板，适用于：

- `小程序banner配置页`
- `小程序瓷片区配置页`
- `小程序金刚区配置页`
- `小程序弹窗配置页`

## 1. 页面骨架必须承接

统一按以下板块抽取，避免只保留“配置页摘要”：

- `filter_area`：搜索/筛选区
- `list_area`：主列表区
- `action_area`：列表上方操作区
- `edit_modal`：添加弹窗；若存在编辑入口，需显式补 `编辑弹窗`
- `sort_modal`：排序弹窗
- `field_rule_table`：触达用户类型或类似字段说明表，用于保留字段语义证据，不默认视为独立配置对象
- `other`：系统说明、黄色便签、补充限制

## 2. 信息维度必须完整

### 2.1 搜索/筛选区

- 字段名
- 控件类型
- 枚举值
- 默认值

### 2.2 列表区

- 列头字段
- 元数据列：创建人、创建时间、修改时间
- 状态列原词
- 图片/样式预览
- 操作列动作

### 2.3 添加/编辑弹窗

每个字段至少补齐：

- `display_name / field_name`
- `data_type / control_type`
- `required`
- `editable`
- `default_value`
- `data_source`
- `enum_values / content_values`
- `conditional_visibility / conditional_editability`

### 2.4 排序弹窗

- 排序对象范围
- 初始顺序
- 关闭/删除后的顺位变化
- 新增后的默认位置

### 2.5 说明表 / 便签

- 触达用户类型每一行
- 附加字段
- 条数上限
- 精确提示语
- 删除限制 / 引用限制
- 状态过滤条件
- 若说明表描述的是某个字段的取值效果、附加字段或分支规则，必须标记为该字段的语义扩展，后续回挂到字段所属 feature

## 3. 后台配置页家族基线

### 3.1 通用基线

所有后台配置页都必须承接：

- 列表区字段 + 操作区入口
- 添加弹窗字段矩阵
- 排序弹窗规则
- 触达用户类型说明表
- 状态原词 `关闭 / 开启`
- 删除前二次确认

补充要求：
- `触达用户类型说明表` 默认是 `触达用户类型` 字段的语义扩展
- 在 testcase 阶段，默认转成“字段枚举效果 / 附加字段联动 / 分支限制”类覆盖，而不是单独查表

### 3.2 家族差异

- `banner`
  - 单 tab 最多 `5条`
- `瓷片区`
  - 单 tab 最多 `4条`
- `金刚区`
  - 单 tab 最多 `4条`
  - 跳转类型包含 `展示企微单人单码`
  - 说明表包含 `付费未添加企微用户`
- `弹窗`
  - 单 tab 最多 `3条`
  - 存在 `展示规则`
  - `展示规则` 默认 `每日首次进入小程序`

## 4. 结构化与 testcase 放行门槛

### 4.1 进入 structured_prd

不得丢失：

- 列头字段
- 操作列行为
- 字段级属性
- 说明表逐行规则
- 删除/引用/上限/默认值规则

### 4.2 进入 testcase

每个后台配置页至少要有：

- 1 条添加/编辑弹窗用例
- 1 条列表字段或列表展示完整性用例
- 1 条操作区或操作列行为用例
- 1 条排序弹窗用例
- 1 条条数上限或删除/引用限制用例
- 1 条字段语义类用例，用于承接 `触达用户类型` 等字段说明表对应的枚举效果或附加字段规则

若存在以下规则，还必须显式承接：

- 触达用户类型说明表
- `选择活动`
- `展示规则`
- 精确默认值
- 引用删除限制与错误提示

说明：
- “显式承接触达用户类型说明表”不等于必须单独生成“查看说明表”用例
- 若说明表只是字段效果说明，优先在 `添加弹窗 / 编辑弹窗 / 条件联动 / 数据规则` 中承接
- 只有说明表本身存在独立展示要求时，才单独出“说明表展示”类用例

## 4.3 Family 复用优先

对 `banner / 瓷片区 / 金刚区 / 弹窗`，先复用同构字段包和 case pack，再补 family 差异，避免每页重新组织一套口径。

参考：
- `skills/prd-image-evidence-extractor/references/config_family_variants.md`
- `skills/case-generation/references/backend_config_family_case_library.md`

## 5. 后台配置页样板回归

每次修改以下任一环节后，优先用“命中后台配置页家族模式”的样板工作项回归：

- `prd-image-evidence-extractor`
- `PRD Structurer`
- `Case Generator`
- review gate / 校验脚本

放行标准：

- `image_evidence -> structured_prd` 映射通过
- 后台配置页家族链路校验通过
- testcase 不回退 `操作区 / 展示规则 / 选择活动 / 列表字段与操作`
