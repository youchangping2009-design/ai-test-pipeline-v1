# Backend Config Family Case Library

适用场景：
- `banner / 瓷片区 / 金刚区 / 弹窗` 这类同构后台配置页
- 需求同时包含筛选区、列表区、操作区、添加/编辑弹窗、排序弹窗、字段说明表、系统说明

目标：
- 把高复用字段与用例骨架沉成可复用规则，避免每次重新发明
- 先复用共性 case pack，再补 family 差异，保证 banner / 瓷片区 / 金刚区 / 弹窗 一致性产出

## 1. 页面骨架复用

默认先识别以下板块：
- `filter_area`
- `list_area`
- `action_area`
- `edit_modal`
- `sort_modal`
- `field_rule_table`
- `other`

其中：
- `field_rule_table` 用于保留截图 / PRD 中的说明表证据
- 若说明表没有独立交互，testcase 默认挂回所属字段所在的 `edit_modal` 或对应业务 feature

## 2. 通用字段包

### 2.1 基础字段包

优先复用以下字段语义，而不是每页重新起一套表述：

- `asset_name`
  - 映射：`banner名称 / 瓷片区名称 / 金刚区名称 / 弹窗名称`
  - 常见规则：文本输入框、必填、`varchar(10)`
- `asset_image`
  - 映射：`banner图片 / 瓷片区样式 / 金刚区样式 / 弹窗图片`
  - 常见规则：图片上传、必填、仅上传一张
- `display_type`
  - 常见规则：下拉单选、必填
  - 常见联动：`display_type -> X`
- `display_after_days`
  - 映射：`X`
  - 常见规则：正整数、条件展示、条件必填
- `touch_user_type`
  - 常见规则：下拉单选、必填、content=`详见表触达用户类型`
  - 常见联动：`touch_user_type -> 人群效果 / 附加字段`
- `jump_type`
  - 常见规则：下拉单选、必填
  - 常见联动：`jump_type -> 选择活动 / 链接 / 企微单人单码`
- `activity_id`
  - 映射：`选择活动`
  - 常见规则：活动中心渠道=小程序活动，状态=发布，按创建时间倒序
- `link_url`
  - 映射：`链接`
  - 常见规则：文本输入、条件展示、活动中心场景可能只展示不允许编辑
- `display_tab`
  - 常见规则：下拉多选、必填、数据来源=导航名称列表
- `status`
  - 常见规则：开关 / 单选、必填、默认关闭、原词保留 `关闭 / 开启`

### 2.2 差异字段包

- `display_rule`
  - 仅弹窗 family 默认启用
  - 常见规则：`每日首次进入小程序 / 每次进入小程序 / 仅一次`

## 3. 通用规则包

优先复用以下共性规则：

- 列表区字段完整展示
- 操作区入口完整展示
- 删除前二次确认
- 单 tab 条数上限
- 排序只展示开启导航
- 初始排序按创建时间
- 删除/关闭后顺位上移
- 已排序后新增置前
- 触达用户类型字段语义扩展

## 4. 通用用例包

生成后台配置页 testcase 时，优先按以下 case pack 组装：

### 4.1 Filter Pack
- 按名称 / 跳转类型 / 状态筛选
- 状态枚举原词保留 `关闭 / 开启`

### 4.2 Field Matrix Pack
- 添加/编辑弹窗字段矩阵完整性
- 承接字段名、控件类型、必填、默认值、可编辑性、数据来源、枚举/content

### 4.3 Conditional Linkage Pack
- `display_type -> X`
- `jump_type -> 选择活动 / 链接 / 企微单人单码`
- `display_rule` 默认值与枚举

### 4.4 List And Ops Pack
- 列表列头完整展示
- 图片/样式预览
- 操作区与操作列入口：`添加 / 编辑 / 复用 / 删除 / 排序`

### 4.5 Sort Pack
- 初始顺序
- 删除/关闭后顺位上移
- 新增置前
- 若需求明确拖拽，则补拖拽后顺序

### 4.6 Limit Pack
- 上限内允许保存
- 超上限保存失败或不进入展示集合
- 提示语原词保留

### 4.7 Touch User Type Pack
- 默认不生成“查看说明表”类 testcase
- 生成“触达用户类型枚举效果 / 附加字段 / 分支限制”类 testcase
- 用例应落在所属弹窗、字段联动或业务规则分组下
- 若存在附加字段，如充值金额区间，需补边界 / 异常验证
- 若不同 family 对人群效果有差异，按差异项补充，而不是重写整组 case

## 5. Family 差异覆盖

### 5.1 banner
- 主字段：`asset_name -> banner名称`，`asset_image -> banner图片`
- 上限：`5条`
- 跳转类型通常为：`无交互 / 活动中心 / 链接`

### 5.2 瓷片区
- 主字段：`asset_name -> 瓷片区名称`，`asset_image -> 瓷片区样式`
- 上限：`4条`
- 常见差异：跨 tab 差异、无交互占位

### 5.3 金刚区
- 主字段：`asset_name -> 金刚区名称`，`asset_image -> 金刚区样式`
- 上限：`4条`
- 跳转类型增加：`展示企微单人单码`
- 触达用户类型增加：`付费未添加企微用户`

### 5.4 弹窗
- 主字段：`asset_name -> 弹窗名称`，`asset_image -> 弹窗图片`
- 上限：`3条`
- 增加字段：`display_rule`
- 常见默认值：`每日首次进入小程序`
- 跳转类型可包含：`展示企微单人单码`

## 6. 组装顺序

推荐先后顺序：
1. 先应用通用字段包
2. 再应用通用规则包
3. 再生成通用用例包
4. 最后补 family 差异

禁止行为：
- 每个 family 都从零开始重写字段矩阵
- 把字段说明表直接当成独立配置页对象
- 用差异项覆盖整套共性 case，导致同构页面命名、覆盖粒度、断言口径不一致
