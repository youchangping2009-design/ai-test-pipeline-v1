## 关键结论

- 这是一个“前台展示 + 后台配置 + 技术约束”联动需求。
- 前台购买页的高优先变更点是：双 tab 生效、宣传图、宣传专区、特价专区、普通区更名为限时购买。
- 后台商品管理的高优先变更点是：商品区字段进入列表与添加弹窗、特殊区数量限制、库存预警联动隐藏和通知。
- 后台宣传内容配置的高优先变更点是：云机类型全覆盖且不重复、宣传图上传限制、口号/性能参数长度、最多 2 条配置。
- 技术约束虽不属于页面字段，但属于必须保留的可执行规则，需要进入结构化 PRD 与测试用例。
