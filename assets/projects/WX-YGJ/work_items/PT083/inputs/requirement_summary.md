## 2. 需求结论

- 通过免费体验云机提升新增用户的云挂机覆盖率。背景材料称日新增盒子用户引入率约 17%，云挂机前三日覆盖率约 3%～4%；两轮 MVP 约覆盖 100 名新用户，破冰率从约 3% 提升到约 10%，其中约 60% 后续购买周卡及以上商品。
- 更新云机 SDK，改善画面模糊、卡顿问题。
- 将云机画面尺寸固定调整为 `720*1280`，以支持用户同时使用脚本。
- 改版 C 端《云挂机购买页》，在{全新版}和{常规版}两个 Tab 下增加宣传位、宣传区和特价专区，并保留普通商品区。
- 扩展 B 端[云手机商品管理]，增加商品区、盒子内排序、库存预警及购买数量报警通知人等配置，并新增《编辑宣传内容》能力。
- PT083 原图与 PT084/PT085 原图逐张同哈希，图片本身未显示新增、删除或变更；该同源关系已由用户确认为迁移前历史基准，当前需求语义不变。

## 5. 面向研发的需求拆解

### C 端《云挂机购买页》

- {全新版}和{常规版}两个 Tab 均应用本次区域改版。
- 宣传位：建议尺寸 `1008*160`；图片来源为 B 端《编辑宣传内容》的“宣传图片”；需保证首屏普通区商品列表能够展示两个及以上商品。
- 宣传区：展示“宣传口号”和“性能参数”，数据来自 B 端对应字段；B 端均限制 20 个字符，C 端超过一行时换行展示。
- 特价专区：区域名称为“特价专区”；展示现价、原价、商品名称、商品标签类型；B 端配置时展示、未配置时隐藏；横向展示，首屏展示 2.5 个商品，最多展示 4 个商品。
- 普通商品区：区域名称为“限时购买”；保留原商品列表和原有数量展示逻辑，采用纵向展示；展示现价、原价、商品名称、商品标签类型。

### B 端[云手机商品管理]

- 列表提供【编辑商品顺序】、【添加】和【编辑宣传内容】入口。
- 商品配置新增或明确“商品区”“盒子内排序”“库存预警值”“购买数量报警通知人”等字段。
- 《添加》表单截图中带必填标识的字段包括：“云手机商品类型”“云机类型”“商品名称”“原价（元）”“现价（元）”“服务时长”“商品区”“盒子内排序”“购买数量报警通知人”。“库存预警值”未显示必填标识，按非必填记录。
- “原价（元）”“现价（元）”：沿用已有能力，数值限制为大于 0。
- “服务时长”：数字选择器，单位包含天、时；后端以秒为单位，天数最大值 370、小时最大值 23，所有输入不能同时为 0。
- “商品区”：单选下拉，选项为{特殊区}/{普通区}。特殊区最多配置 4 个商品；超限时不可保存，并提示「特殊区只能展示4个商品，当前字段的配置数量已超过4个，请关闭之前的商品或调整配置」。
- “盒子内排序”：正整数，最大值 1000；排序值相同时按创建时间倒序排列。
- “商品展示时间”：沿用已有能力；未配置时提示“未配置，云挂机商品则长期展示”。截图还要求服务时长结束后 C 端不再展示内容，准确口径待确认。
- “库存预警值”：正整数，最大值 200；系统按固定频率校验云机库存是否小于等于配置值。库存充足时 C 端正常展示并分配云机；库存不足时 C 端隐藏商品且不分配云机，同时通知管理员大仓。
- “购买数量报警通知人”：单选下拉，候选内容为盒子后台管理员列表。
- 库存不足告警发往“云手机相关报警”群；正式环境模板标题为「【云挂机库存不足通知】」，内容包含功能模块、配置 ID、商品名称、云机类型、云机服务时长、通知时间和通知人。

### B 端《编辑宣传内容》

- “云机类型”：必填、单选下拉，选项为盒子现有云机类型（截图列出{全新版}/{常规版}）。保存前需保证所有云机类型均已配置且没有重复；失败时不可保存，并提示「所有云机类型都需要配置宣传内容，且云机类型不重复」。
- “宣传图片”：必传；单条配置最多上传 5 张，支持拖拽排序；支持 `gif/jpg/jpeg/png`，单张最大 500 KB，建议尺寸 `1008*160`；鼠标悬停时可删除图片。
- “宣传口号”“性能参数”：必填文本框，最多 20 个字符；C 端超过一行时换行展示。
- 【新增】用于增加一块由云机类型、宣传图片、宣传口号和性能参数组成的配置。截图说明最多额外新增 1 块，配置达到 2 条时禁用按钮；新增内容在 C 端全屏展示。
