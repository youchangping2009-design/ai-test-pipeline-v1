## Top Explicit Rules
- `ER-001` 通过免费体验云机提升新增用户的云挂机覆盖率。背景材料称日新增盒子用户引入率约 17%，云挂机前三日覆盖率约 3%～4%；两轮 MVP 约覆盖 100 名新用户，破冰率从约 3% 提升到约 10%，其中约 60% 后续购买周卡及以上商品。
- `ER-002` 更新云机 SDK，改善画面模糊、卡顿问题。
- `ER-003` 将云机画面尺寸固定调整为 `720*1280`，以支持用户同时使用脚本。
- `ER-004` 改版 C 端《云挂机购买页》，在{全新版}和{常规版}两个 Tab 下增加宣传位、宣传区和特价专区，并保留普通商品区。
- `ER-005` 扩展 B 端[云手机商品管理]，增加商品区、盒子内排序、库存预警及购买数量报警通知人等配置，并新增《编辑宣传内容》能力。
- `ER-006` PT083 原图与 PT084/PT085 原图逐张同哈希，图片本身未显示新增、删除或变更；该同源关系已由用户确认为迁移前历史基准，当前需求语义不变。
- `ER-007` ### C 端《云挂机购买页》
- `ER-008` {全新版}和{常规版}两个 Tab 均应用本次区域改版。

## Top Implicit Rules
- `IR-001` 云手机商品管理中的商品区、排序、商品信息和库存配置，以及编辑宣传内容中的图片、口号、性能参数和云机类型，共同决定云挂机购买页对应版本Tab的展示结果。

## Key Risks
- `RISK-001` [high] SDK 更新缺少目标版本和画质、流畅度量化验收口径。
- `RISK-002` [high] `720*1280` 的技术语义、终端适配和触控边界未明确。
- `RISK-003` [high] 库存阈值同时影响商品展示、云机分配和告警，但频率、并发和恢复口径未明确。
- `RISK-004` [medium] B 端特殊区配置上限与 C 端特价专区展示上限必须保持一致。
- `RISK-005` [medium] 未展开的编辑/排序弹窗及下拉枚举不得按添加表单或当前值推断。

## Ambiguities
- `AMB-001` 两份活动复盘正文不可访问，免费体验业务规则未展开。
- `AMB-002` 720*1280技术层级、脚本接入方式和画质阈值未说明。
- `AMB-003` 轮播交互和默认图规则未说明。
- `AMB-004` 原有商品数量和其他既有逻辑未定义。
- `AMB-005` 无法确认完整枚举和真实默认值。
- `AMB-006` 图片仅显示编辑入口。
- `AMB-007` 排序弹窗未展开。
- `AMB-008` 既有字段完整枚举、默认值、数据源和商品展示时间控件未展开。
- `AMB-009` 库存校验频率和商品展示时间部分文字模糊。
- `AMB-010` 未提供SDK版本、尺寸技术层级、适配终端或发布策略。

## Recommended Test Dimensions
- `TD-001` 字段必填与默认值：只按图片星号区分必填，不把控件类型升级为强校验。
- `TD-002` 特殊区容量与展示联动：B 端配置、状态和 C 端最多 4 个展示需一致。
- `TD-003` 排序值与同值排序：覆盖正整数上限及创建时间倒序，未展开排序弹窗保持待确认。
- `TD-004` 库存阈值与告警链路：覆盖阈值临界值，频率、并发和恢复口径不脑补。
- `TD-005` 宣传内容字段约束：覆盖云机类型完整唯一、图片约束和 20 字符边界。
- `TD-006` 后台配置到 C 端展示面投影：保留商品与宣传配置到两个版本 Tab 的同源映射。
- `TD-007` SDK、分辨率与脚本兼容性：待确认项不升级为未经证明的硬断言。
