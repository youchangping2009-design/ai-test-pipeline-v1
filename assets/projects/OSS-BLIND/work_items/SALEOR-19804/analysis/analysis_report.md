## Top Explicit Rules
- `ER-001` 调用 `giftCardBulkCreate` 创建新一批礼品卡并复用已有标签时，只能把新礼品卡追加到标签关系，不能移除该标签与历史礼品卡之间的关联。连续批次使用相同、部分重叠或完全不同的标签集合后，每个标签都应保留其全部正确礼品卡成员。
- `ER-002` 对已存在标签，将新创建礼品卡加入已有关系，而不是替换该标签的完整礼品卡集合。
- `ER-003` 对新标签，创建标签后关联当前批次礼品卡。
- `ER-004` 一次批量创建的返回数量、错误列表和礼品卡标签结果保持既有接口契约。
- `ER-005` 关系更新应支持批量数量，不引入与历史礼品卡数量线性失控的额外查询。
- `ER-006` 第二批复用第一批标签后，第一批礼品卡仍保留该标签。
- `ER-007` 两批标签集合完全相同、部分重叠和完全不重叠时，逐标签核对成员集合。
- `ER-008` 新批次每张礼品卡只获得本次输入指定的标签。

## Key Risks
- `RISK-001` [medium] 关系替换与追加在单批次中可能都表现正常，必须跨批次检查历史关系。
- `RISK-002` [medium] 大批量礼品卡和高复用标签可能引入查询次数或关系写入性能风险。
- `RISK-003` [high] 并发批量创建复用同一标签时的锁、唯一性和最终成员集合未明确。
- `RISK-004` [high] 修复是前向修复，历史已丢失关系不可从数据库自动推导。
